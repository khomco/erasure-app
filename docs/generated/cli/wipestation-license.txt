Vendor licensing tools (ADR-0005).

`new-root` and `issue` are *vendor-side* operations. In production the root private key never leaves an offline signer and these run there, not on a station.

Usage: wipestation license <COMMAND>

Commands:
  new-root  Generate a vendor root keypair. Writes the 32-byte seed and prints the public key to publish
  issue     Issue a licence binding an instance key to entitlements
  inspect   Print a licence and, given roots, whether it verifies
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')
